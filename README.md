# بات تولید ریل دکوراسیون داخلی

این مخزن نسخهٔ اجرایی اولیهٔ مدیر محتوای تلگرامی است. کارفرما رسانه و توضیح را می‌فرستد؛ بات با OpenAI API طرح و متن می‌سازد و **در یک پیام** برای تأیید پیش از ساخت ارائه می‌کند. ویس فارسی/عربی از خود کارفرما گرفته می‌شود؛ انگلیسی صدای تولیدی می‌گیرد. رندر از فایل‌های واقعی پروژه با FFmpeg انجام می‌شود و تحویل به تأیید نسخهٔ مشخص MP4 وابسته است.

## راه‌اندازی روی هاست لینوکس

1. `cp .env.example .env` و مقادیر `TELEGRAM_BOT_TOKEN`، `ALLOWED_TELEGRAM_CHAT_IDS` و `OPENAI_API_KEY` را تکمیل کنید. کلیدها را در مخزن ثبت نکنید.
2. `docker compose up -d --build` را اجرا کنید. بات با long polling کار می‌کند و به webhook یا دامنه نیاز ندارد.
3. برای آپلود ویدیوهای بزرگ، یک دامنهٔ HTTPS را با reverse proxy به `127.0.0.1:8000` وصل کنید و `PUBLIC_BASE_URL` و `UPLOAD_SECRET` را تنظیم کنید. سپس سرویس‌ها را دوباره راه‌اندازی کنید. تا آن زمان فایل‌های زیر ۲۰ مگابایت از تلگرام دریافت می‌شوند؛ [این محدودیت دانلود Bot API است](https://core.telegram.org/bots/api#getfile).
4. در تلگرام `/start` و سپس `/new` را بزنید، زبان و فایل‌ها را انتخاب کنید و «فایل‌ها تمام شد» را بزنید.

برای اجرای بدون Docker، Python 3.11+ و `ffmpeg`/`ffprobe` با پشتیبانی `libx264` و `libass` لازم است. پس از `pip install -e .`، با متغیرهای محیطی درست `reelbot` و در صورت نیاز `uvicorn reelbot.upload:app --host 127.0.0.1 --port 8000` را اجرا کنید.

## اجرای محلی ویندوز

فایل `.env` این workspace ساخته شده و مقادیر محرمانهٔ آن خالی‌اند. توکن بات و بعداً کلید OpenAI را **روی سیستم خودتان** در آن وارد کنید؛ محتویات فایل را در چت نفرستید. سپس از همین پوشه `python -m pip install -e '.[dev]'` و `reelbot` را اجرا کنید. برای یافتن شناسهٔ گفت‌وگو، در بات `/whoami` را بفرستید، عدد پاسخ را در `ALLOWED_TELEGRAM_CHAT_IDS` قرار دهید و بات را دوباره اجرا کنید. FFmpeg با Winget در سطح کاربر نصب شده است؛ اگر ترمینال قدیمی آن را نمی‌بیند، ترمینال تازه باز کنید. بدون کلید OpenAI، بات می‌تواند فایل‌ها را بگیرد اما سناریو نمی‌سازد و دکمهٔ «فایل‌ها تمام شد» را برای پس از فعال‌سازی نگه می‌دارد.

## مرز فعلی اجرای خودکار

- مدیر محتوا، دریافت فایل، تأیید طرح، نسخه‌بندی، صف، تدوین از تصاویر واقعی، پیش‌نمایش و تأیید تحویل پیاده شده‌اند.
- تولید خودکار شاتِ کاراکتر با Higgsfield **تا آزمون OAuth، کشف ابزارهای مجاز MCP و ثبت نرخ واقعی حساب فعال نیست**. اگر طرح تأییدشده حضور کاراکتر بخواهد، job به صف بررسی می‌رود و ویدیوی متفاوتی به‌جای آن ساخته نمی‌شود. [MCP از کردیت اشتراک استفاده می‌کند، ولی Unlimited وب در MCP اعمال نمی‌شود](https://higgsfield.ai/creator-hub/help-center/integrations/what-is-higgsfield-mcp).
- کنترل کد روی هزینهٔ OpenAI از رزرو پیش از فراخوان استفاده می‌کند. برای سقف پرداخت واقعی، در [OpenAI Platform حد سخت پروژه را روی ۱۰ دلار و گزینهٔ Enforce a hard limit را فعال کنید](https://developers.openai.com/api/docs/guides/spend-limits)؛ اعمال آن ممکن است کمی تأخیر داشته باشد. هزینهٔ صوت در بعضی پاسخ‌ها به‌صورت توکن برنمی‌گردد.
- نسخهٔ فعلی زیرنویس را بر اساس متن و مدت ویس زمان‌بندی می‌کند؛ هم‌زمانی کلمه‌به‌کلمه و تأیید بصری فارسی/عربی در پایلوت واقعی باید بررسی شود.
- فایل‌ها و SQLite در volume خصوصی `reel_data` هستند. برای استفادهٔ واقعی، از این volume پشتیبان‌گیری کنید و بازیابی را امتحان کنید.
- در استثناهای رسانه، اپراتور می‌تواند با `reelbot-admin retry ID` دوباره تلاش کند یا MP4 پولیش‌شدهٔ منطبق با همان طرح را با `reelbot-admin complete ID /path/to/final.mp4` برای تأیید نهایی کارفرما بفرستد. `reelbot-admin report` مصرف رزروشدهٔ OpenAI را نشان می‌دهد.

## آزمون

`python -m pip install -e '.[dev]'` سپس `python -m pytest -q`. آزمون واقعی رندر به FFmpeg نصب‌شده و آزمون واقعی بات/مدل به کلیدهای سرویس نیاز دارد. هیچ تستی بدون تأیید طرح، تولید پولی Higgsfield را فراخوانی نمی‌کند.
