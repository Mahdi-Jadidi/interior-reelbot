# بات تولید ریل دکوراسیون داخلی

این مخزن نسخهٔ اجرایی اولیهٔ مدیر محتوای تلگرامی است. کارفرما رسانه و توضیح را می‌فرستد؛ بات با MiA Router طرح و متن می‌سازد و **در یک پیام** برای تأیید پیش از ساخت ارائه می‌کند. رندر از فایل‌های واقعی پروژه با FFmpeg انجام می‌شود و تحویل به تأیید نسخهٔ مشخص MP4 وابسته است.

## راه‌اندازی روی هاست لینوکس

1. `cp .env.example .env` و مقادیر `TELEGRAM_BOT_TOKEN`، `ALLOWED_TELEGRAM_CHAT_IDS` و `AI_ROUTER_API_KEY` را تکمیل کنید. کلید را از داشبورد MiA Router بگیرید و فقط در فایل محلی `.env` بگذارید؛ آن را در چت یا مخزن ثبت نکنید. نشانی API پیش‌فرض `https://miarouter.online/v1` است و بات از endpoint سازگار با Chat Completions استفاده می‌کند.
2. `docker compose up -d --build` را اجرا کنید. بات با long polling کار می‌کند و به webhook یا دامنه نیاز ندارد.
3. برای آپلود ویدیوهای بزرگ، یک دامنهٔ HTTPS را با reverse proxy به `127.0.0.1:8000` وصل کنید و `PUBLIC_BASE_URL` و `UPLOAD_SECRET` را تنظیم کنید. سپس سرویس‌ها را دوباره راه‌اندازی کنید. تا آن زمان فایل‌های زیر ۲۰ مگابایت از تلگرام دریافت می‌شوند؛ [این محدودیت دانلود Bot API است](https://core.telegram.org/bots/api#getfile).
4. در تلگرام `/start` و سپس `/new` را بزنید، زبان و فایل‌ها را انتخاب کنید و «فایل‌ها تمام شد» را بزنید.

برای اجرای بدون Docker، Python 3.11+ و `ffmpeg`/`ffprobe` با پشتیبانی `libx264` و `libass` لازم است. پس از `pip install -e .`، با متغیرهای محیطی درست `reelbot` و در صورت نیاز `uvicorn reelbot.upload:app --host 127.0.0.1 --port 8000` را اجرا کنید.

## اجرای محلی ویندوز

فایل `.env` این workspace محلی و محرمانه است. توکن بات و کلید MiA Router را **روی سیستم خودتان** در آن وارد کنید؛ محتویات فایل را در چت نفرستید. سپس از همین پوشه `python -m pip install -e '.[dev]'` و `reelbot` را اجرا کنید. برای یافتن شناسهٔ گفت‌وگو، در بات `/whoami` را بفرستید، عدد پاسخ را در `ALLOWED_TELEGRAM_CHAT_IDS` قرار دهید و بات را دوباره اجرا کنید. FFmpeg با Winget در سطح کاربر نصب شده است؛ اگر ترمینال قدیمی آن را نمی‌بیند، ترمینال تازه باز کنید. بدون کلید MiA Router، بات می‌تواند فایل‌ها را بگیرد اما سناریو نمی‌سازد و دکمهٔ «فایل‌ها تمام شد» را برای پس از فعال‌سازی نگه می‌دارد.

## مرز فعلی اجرای خودکار

- مدیر محتوا، دریافت فایل، تأیید طرح، نسخه‌بندی، صف، تدوین از تصاویر واقعی، پیش‌نمایش و تأیید تحویل پیاده شده‌اند.
- تولید خودکار شاتِ کاراکتر با Higgsfield **تا آزمون OAuth، کشف ابزارهای مجاز MCP و ثبت نرخ واقعی حساب فعال نیست**. اگر طرح تأییدشده حضور کاراکتر بخواهد، job به صف بررسی می‌رود و ویدیوی متفاوتی به‌جای آن ساخته نمی‌شود. [MCP از کردیت اشتراک استفاده می‌کند، ولی Unlimited وب در MCP اعمال نمی‌شود](https://higgsfield.ai/creator-hub/help-center/integrations/what-is-higgsfield-mcp).
- برنامه‌ریزی متن+تصویر با Chat Completions در MiA Router انجام می‌شود. داشبورد فعلی `claude-sonnet-5` را با قیمت نمایشی $0.25 برای هر درخواست نشان می‌دهد؛ اگر هر ۶۰ ریل یک طرح بخواهند، این مرحله حدود $15 می‌شود. اعتبار $10 برای حدود ۴۰ درخواست برنامه‌ریزی کافی است، پیش از هزینهٔ اصلاحات. قیمت‌ها و شناسهٔ مدل‌ها را پیش از استفاده در داشبورد بررسی کنید؛ سقف داخلی برنامه، صورتحساب MiA Router را محدود نمی‌کند.
- MiA Router در داشبورد فعلی مسیر Chat Completions را نشان می‌دهد و endpoint تبدیل گفتار به متن یا تولید صدا دیده نمی‌شود. بنابراین ویس ورودی، تطبیق ویس فارسی/عربی و TTS انگلیسی هنوز برای استفادهٔ واقعی نیازمند سرویس صوتی جداگانه/محلی هستند.
- نسخهٔ فعلی زیرنویس را بر اساس متن و مدت ویس زمان‌بندی می‌کند؛ هم‌زمانی کلمه‌به‌کلمه و تأیید بصری فارسی/عربی در پایلوت واقعی باید بررسی شود.
- فایل‌ها و SQLite در volume خصوصی `reel_data` هستند. برای استفادهٔ واقعی، از این volume پشتیبان‌گیری کنید و بازیابی را امتحان کنید.
- در استثناهای رسانه، اپراتور می‌تواند با `reelbot-admin retry ID` دوباره تلاش کند یا MP4 پولیش‌شدهٔ منطبق با همان طرح را با `reelbot-admin complete ID /path/to/final.mp4` برای تأیید نهایی کارفرما بفرستد. `reelbot-admin report` رزرو داخلی MiA Router را نشان می‌دهد.

## استفاده از ChatGPT Plus

در کد فعلی، مدل از MiA Router استفاده می‌کند و اشتراک Plus خودکار به بات دسترسی نمی‌دهد. OpenAI مسیر جداگانهٔ Sign in with ChatGPT را برای برنامه‌های محلی و متن‌باز مستند کرده است؛ این مسیر به OAuth و رضایت جداگانه برای مصرف سهمیهٔ Plus نیاز دارد و به نشست فعلی ChatGPT متصل نیست. مستند رسمی، اپ‌های پولی یا میزبانی‌شده را به درخواست دسترسی ارجاع می‌دهد. مجوز DevKit رسمی نیز استفاده از کد آن را به کاربرد غیرتجاری محدود می‌کند؛ چون بات برای ارائهٔ خدمات محتوایی به مشتری کسب‌وکار استفاده می‌شود، کد DevKit را بدون مجوز کتبی تجاری وارد نکرده‌ایم. تا روشن‌شدن مجوز و واجدشرایط‌بودن این کاربرد، MiA Router مسیر فعال باقی می‌ماند. [راهنمای رسمی Sign in with ChatGPT](https://learn.chatgpt.com/cookbook/articles/sign-in-with-chatgpt) · [مجوز DevKit](https://github.com/openai/sign-in-with-chatgpt-devkit/blob/main/LICENSE).

## آزمون

`python -m pip install -e '.[dev]'` سپس `python -m pytest -q`. آزمون واقعی رندر به FFmpeg نصب‌شده و آزمون واقعی بات/مدل به کلیدهای سرویس نیاز دارد. هیچ تستی بدون تأیید طرح، تولید پولی Higgsfield را فراخوانی نمی‌کند.
